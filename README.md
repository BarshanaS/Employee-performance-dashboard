# Employee Performance Dashboard

## Project Overview

An interactive Employee Performance Dashboard developed using Excel/WPS Spreadsheet to analyze employee performance, sales, attendance, achievement, department-wise and monthly performance.

## Objectives

- Analyze employee performance
- Track sales performance
- Monitor attendance
- Evaluate achievement levels
- Compare department-wise performance
- Analyze monthly performance
- Create an interactive and user-friendly dashboard

## Tools Used

- Microsoft Excel / WPS Spreadsheet
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
